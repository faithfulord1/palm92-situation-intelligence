# Security and Responsible Use

Palm92 Situation Intelligence is intended for lawful situational awareness, resilience, public-interest analysis, and governed operational support.

Do not use this project to identify, stalk, target, or persistently track individuals. Do not add covert surveillance features, weapon-targeting workflows, or personal-data enrichment without a lawful basis and a formal governance review.

Security issues should be reported privately to the repository owner rather than disclosed publicly before remediation.
