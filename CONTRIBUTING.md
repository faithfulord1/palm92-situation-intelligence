# Contributing

Thank you for helping improve Palm92 Situation Intelligence.

## Good contributions

Useful contributions include new lawful public-data adapters, data-quality checks, accessibility improvements, tests, documentation, incident schemas, privacy-preserving visualisation, resilience tooling, and domain packs.

## Not accepted

Do not submit covert person tracking, facial recognition, licence-plate tracking, stalking, weapon-targeting workflows, doxxing features, credential harvesting, or autonomous consequential-action tooling.

## Pull requests

Keep changes small, explain the source and licence of any new data feed, document new environment variables, preserve provenance, and label inference separately from observed evidence.
